# resume-os

An interactive retro OS-themed resume. Built with vanilla HTML, CSS, and JavaScript.

## Theme Gallery

Switch between classic operating system themes:

- **Mac OS 7/8** - Classic Platinum interface (1997-2001 era)
- **Mac OS 9** - Brushed metal and aqua blues
- **Mac OS X Aqua** - The iconic translucent blue interface
- **Windows 3.1** - Microsoft's landmark 16-bit era (1985)
- **Windows XP** - Modern blue and green (2001)
- **BeOS** - Haiku's predecessor, geometric and bold

Each theme includes period-accurate typography, window chrome, icons, and desktop patterns.

## Navigation

- **Double-click** desktop icons to open windows
- **Drag windows** by their titlebars
- **Resize windows** using the bottom-right corner
- **Close windows** with the close button (top-left)
- **Right-click desktop** for screensaver menu
